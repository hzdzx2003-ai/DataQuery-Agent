## 用户与场景

目标用户是需要快速查看经营数据、但不会编写 SQL 的商业地产运营人员。第一版只覆盖资产、铺位、租户、租约、租金回款和运营费用。

## 固定时间基准

- `as_of_date`: `2026-09-01`
- “上个月”: `2026-08-01` 至 `2026-08-31`
- 数据覆盖: `2025-01` 至 `2026-08`

固定时间基准用于保证自然语言题、Gold SQL 和测试结果可重复。

## V1 范围

### 包含

- 中文自然语言问题
- 单个 SQLite 数据库
- 指标存在性和歧义判断
- Text-to-SQL
- 表、字段、别名、JOIN 和只读安全校验
- 最多两轮基于明确错误原因的 SQL 修正
- 中文结果与中文可行动错误提示
- 20 条离线评测
- 极简本地 UI

### 不包含

- 多数据库联邦查询
- 企业级权限体系
- 长期记忆
- 预测模型
- 会计利润、税务和估值结论
- 公网托管的无限量免费 Demo

## 成功指标

- 路由准确率：直接执行 / 执行并披露 / 澄清 / 拒答分类正确率
- SQL 执行率：应执行题中成功运行的比例
- 结果正确率：执行结果与 Gold SQL 一致的比例
- 幻觉拦截率：不存在字段或指标在执行前被拦截的比例
- 错误可理解率：失败时是否给出中文原因和下一步建议
- 平均修正轮数与最终修正成功率
