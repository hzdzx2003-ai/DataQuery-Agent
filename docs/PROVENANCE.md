# 独立性与公开边界

## 可以公开

- 本仓库原创代码与文档
- 本项目独立设计的商业地产表结构
- 使用确定性规则与固定随机种子生成的虚构数据
- 本项目自行定义的 24 条 v2 评测题和 Gold SQL
- 在本仓库真实运行得到的测试结果、截图和录屏
- 对通用 Text-to-SQL 问题的分析与改进方法

## 不可以进入本仓库

- 任何第三方专有项目的源代码、Prompt、Skill 文本或配置文件
- 任何第三方专有数据、Schema、截图、品牌名或内部路径
- 任何未经本仓库独立复现的准确率、客户、实验结果或业务成果
- 供应商 API Key、个人账号信息或付费凭证

## 方法借鉴边界

可以研究公开论文和产品中通用的方法，例如检索、Rerank、SQL 校验、错误修正和离线评测；实现时必须重新设计代码、数据、提示词和实验，并只陈述本仓库实际完成和复现的结果。

## 公开声明原则

- 只陈述本仓库可以复现的实现和结果。
- 明确区分产品定义、AI 辅助实现、人工审阅与真实运行证据。
- 不把公开方法描述为原创算法，也不把未运行的目标指标描述为成果。
