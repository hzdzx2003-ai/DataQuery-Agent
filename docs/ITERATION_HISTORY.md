## 2. 语义约束探索 · Phase 7—9C

以下保留原首页的阶段记录；这些发现描述当时的迭代背景，不直接代表NL-v3发布状态。阶段细节在已公开材料中的覆盖程度不同，不将阶段记录等同于新增实测。

| 阶段 | 发现 | 产品决策 |
|---|---|---|
| Phase 7 | 规则层可减少静默错误，但过度干预明显 | 不把开发集通过率当作产品可用性 |
| Phase 8 | 扩充词表无法可靠覆盖开放表达 | 从“枚举措辞”转向“模型理解 + 机械审查” |
| Phase 9A | 模型可能遗漏原文或错误声明请求类型 | 引入完整分段覆盖、写请求前置防护和 Gate 最终决策权 |
| Phase 9B | 模型提供字符 offset 容易造成机械失败 | 改为有序原文分段，由代码重建位置 |
| Phase 9B v2 | 真实冒烟仍出现静默执行歧义和过度干预 | 保留失败证据，不进入 SQL/用户测试，继续最小迭代 |
| Phase 9C | 歧义规则没有同时进入提示与机械判断 | 将 catalog 歧义指导注入 Resolver，并由 Gate 独立执行 |


相关设计：[历史产品案例](PRODUCT_CASE_STUDY.md) · [早期路由](ROUTING.md) · [早期执行链路](PIPELINE.md)。

## 3. 自然语言业务计划 · NL-v3

将开放表达转为结构化目标、时间、筛选、分组排序及口径条件。共性改动包括过度澄清、时间排序、组内前N和已知条件保留。已测质量配置为Max思考开启，固定100题完整通过93题。

后端进一步使用固定指标公式与参数化SQL，保存的70个查询计划回放结果全部匹配参考计算。源码与评测包于2026-10-06公开：[版本更新](../releases/nl-v3-93/CHANGELOG.md) · [复核入口](../releases/nl-v3-93/README.md)。

历史Plus与后续Max的57个同题输出按相同Gold复核，完整通过41→54。这是代码与模型共同升级的回顾性比较；原判定及敏感性说明见[测量方法](EVALUATION_202610.md)。

## 4. 响应速度实验 · 单独配置

关闭思考的完整100题实验为91/100、平均模型任务耗时5.09秒。固定20题的开/关对照均17/20完整通过，平均任务耗时13.81→5.81秒。保留质量与延迟两种配置，不将不同配置的最佳数字合并。

证据：[性能实验](../experiments/no-thinking-100/README.md) · [测量范围](EVALUATION_202610.md)。
